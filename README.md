# Devace-93/tap

Homebrew tap for [MouseTouch](https://github.com/Devace-93/mousetouch), Apple
Magic Mouse multitouch gestures for Linux/Wayland.

```sh
brew install Devace-93/tap/mousetouch
```

Then follow the printed caveats (install the udev rule once, start the user
service). `Formula/mousetouch.rb` is updated by the mousetouch release
workflow on every tagged release.
